我是一名关注临床数据与统计分析的从业者，也是一位喜欢在业余时间独立开发的实践者。工作中，我重视数据质量、分析逻辑和可复现性；工作之外，我喜欢把日常遇到的问题转化成简单、实用的数字产品。

- 📊 **临床数据与统计：** 使用 **SAS**、**R** 进行临床编程与数据分析
- 🛠️ **独立开发：** 从一个小问题出发，尝试设计、开发并打磨可用的工具
